# 独立道岔操作工具

## 范围和负责模块

CURRENT：已实现并通过离线自动化测试，完整 Folia 服务器交互和客户端画面尚未验证。

BukkitPlugin 提供独立的 `TurnoutWand`，把玩家选择转换成已经存在的安全手动切换请求。
它是进路录制之前的操作工具，不是进路编辑器；不创建道岔、保护区域、资源或行车授权。
RailWand负责轨道与接点建造；独立TurnoutWand只操作已有合法通路。规则预设、全区域通路预览和进路录制不在此批范围。

## 分阶段建造的未完成接点

RailWand允许先创建两条直线和渡线，再补公共腿。选中端点只声明准确接点联结，由Core扩展完整已知成员并派生合法通路；
不因两条同侧腿共点就把它们直接接通。公共腿缺失的组显示本地化“接点未完成”，仍可从任一成员继续补线。
TurnoutWand对该组没有可选合法出口时拒绝切换；空通路不能被UI或默认选路解释成互通。

端点维护和标记读取`TopologyState.endpointGroupAt`，不扫描同坐标附近的无关轨道。未完成组参与既有道岔几何维护保护；
普通双端连续接头仍按普通接头处理。首次创建同侧支腿也必须用Core共享方向判定排除自动坡度平滑的折返链，
不能等组已创建后才保护相邻几何。连接/映射回滚、prepared undo/rebase、保存重载必须携带独立组成员；
只有编辑事务成功后才刷新标记，失败不显示未提交状态。Core合同见[接点持久化](../../javarailways/core/persistence.md#显式目标端点的保存和恢复)。

## 玩家的一次操作

`/jr wand turnout` 发放工具，沿用 `javarailways.admin`；实际使用也必须检查权限，不能通过转交物品绕过。
左键选择来向轨道的道岔端点，右键选择出口并尝试接通。潜行右键显示帮助并读取当前连接，
潜行左键空气清空选择。所有显示均读取真实选择，拒绝后不能把目标支路画成已经接通。

例如直向与侧向都接在同一来向端口：玩家先选来向，再点侧向，后端检查后才扳动；
如果列车正在使用道岔，保持原来连接并提示占用或资源冲突。
从支线向干线操作使用同一逻辑，不把道岔的一侧硬编码成唯一可操作的“正面”。

## 端点选择和实际状态

复用已有轨道瞄准功能，范围 96 米、距视线容差 1.5 米。由命中的轨道弧长确定较近的 A/B 端点，
用当前不可变拓扑的 `structuralNodeAt` 查询是否属于 `TopologyNode.Turnout`。
右键目标必须是同一道岔的不同端口，且属于所选来向的 `legalContinuations`。
不沿普通二度连接寻找远处道岔，不根据相近空间位置猜测轨道连接，也不为 UI 构造另一份图。

读取所选端口朝向接头的 `RailView.nextActiveRail` 得到实际出口，并检查出口一侧是否也选择返回来向。
单侧指向和两侧已对齐必须区分，不能只读一侧就宣称通路已接通。
短暂粒子只覆盖端口附近最多约 5 米，每段最多 9 个点：青色标示来向，绿色标示相互接通，橙色标示单侧指向。
没有持续预览定时器；它们是本次操作的反馈，不承诺跟随之后的自动道岔变化。

## 切换接口和生命周期

工具调用 `InfrastructureResourceService.selectTurnout(plugin, worldId, request): CompletableFuture<ManualTurnoutSelectionResult>`，请求为
`ManualTurnoutSelectionRequest(topologyRevision, fromPort, toPort)`。
适配器将完整操作提交所属world的协调器，执行时复核插件和确切world/runtime；Basic同步apply检查帧间阶段、
结构版本和合法连接，通过短暂资源占用排除其他申请，检查端口附近车体占用，最后执行双侧选择并释放短暂占用。
真实变化后刷新同epoch的共享世界观测，再完成Future。工具在Future实际完成后回到player owner反馈，不能把排队当成扳动成功。
工具不能直接调用 `selectNextRail`，也不重复实现占用判断。
这条 API 不产生 `grant` 或移动授权，不更改车尾释放队列。具体安全算法仍由 Basic 所有。

工具选择只在内存保存世界 UUID、准确拓扑根和稳定端点；不保存可变 Rail 对象或授权。
重新解码物品状态时不恢复临时选择。世界切换、world 实例重建，或所选轨道的 incarnation、接点成员、合法通路及相关平交发生变化后必须重选；
通过 `TopologyState.preservesRails` 验证的无关编辑允许保留选择，不能只因整个世界的 revision 或拓扑根变化就清空它。
世界切换事件直接清空临时状态，因此从 A 世界去 B 再返回 A，也不会恢复原选择或继续之前的切换操作。
沿用 AbstractWand 的物品识别、清空与退出处理；新增工具不改变世界/信号存档格式，不增加旧开发格式兼容。
事件中的玩家访问保持 player owner，铁路读取/切换遵守现有 simulation serialization。
无新线程、跨插件调度接口或在物理线程等待 Bukkit 显示的行为。

耗时的瞄准查询交给已有选轨服务，完成后通过 `PlatformDispatcher.runForEntity` 回到玩家所属线程。
每位玩家至多有一次本工具的瞄准查询在处理；清空选择、查看帮助和退出使旧查询结果失效。
回调还需确认插件/玩家仍可用、仍持有同一工具状态、玩家和铁路世界实例未变化、命中轨道在当前拓扑中仍满足局部有效性，
然后才允许调用安全切换。拒绝旧回调是为了防止玩家已取消操作、工具却在稍后自行扳动道岔。
成功、失败或玩家已退出都要结束本次查询登记，不能让后续点击永久停在“正在定位”。

## 拒绝和反馈

- 未选来向、未命中轨道、命中端不是道岔：提示重新选择，不调用切换接口。
- 目标是同一端口、其他道岔或不合法连接：拒绝，不直接扳动任何轨道。
- `STALE_TOPOLOGY` 或所选轨道的局部结构已改变：清除过期选择并要求重选。
- `WORLD_UNAVAILABLE`：停止操作，不把缺世界解释为未占用。
- `PHYSICALLY_OCCUPIED` / `RESOURCE_CONFLICT`：显示原因，保留实际连接；不强制解除占用。
- `SELECTED` / `UNCHANGED`：分别说明切换完成或本来已经接通，随后重新读取真实选择。

## 成本与退化边界

选轨复用宿主已有空间查询，成本由该查询的候选轨道和曲线采样决定，不宣称常数时间。
目标解析只查询选中轨道的一个端点和一个道岔的合法出口，不扫描整个路网。
显示是每次点击的固定上限点数；空闲工具没有每 tick 开销。
安全切换仍承担既有 Basic 物理占用查询成本，不因接入 UI 而增加第二次占用扫描。
不在本批重写安全接口、优化物理占用索引或扩展为整条通路搜索。

## 验证与后续边界

测试必须验证 A/B 端点和真实拓扑、正反向切换、非法端口、过期选择、换世界、权限、命令注册及建议、
物品状态解码、双侧当前连接和所有后端结果的反馈。使用真实 Core 拓扑，不只验证手写出口列表。
复用 Basic 既有手动选择测试，证明占用/资源拒绝不改变选择，成功不留下长期占用。
UI 测试或记录式粒子输出不能代替真实 Folia/客户端体验验证。

本批离线验证：BukkitPlugin 全量 348 项，Basic 手动选择聚焦 4 项，均通过；宿主 shadowJar 实际重建并检查工具与中英资源入包。
当前取消/过期测试执行生产判定函数，正反向切换测试执行真实 Core 和宿主服务。
换世界事件接线通过源码复核，完整异步调度及客户端画面尚未实测。

不得把绿色标记当作行车允许信号：它只说明这次读取中两侧选择相互匹配，
列车仍要经过正常资源申请及 ATO 限制。完整保护区域通路预览和保存固定进路需要另外实现。
不用为了未来的道岔动画、信号规则预设或存档兼容增加占位状态或新的资源模型。
