# 从当前通路预览录制固定进路

## 状态与负责范围

已改为鼠标确认及进路替换，并通过独立离线检查。预览计算本身仍然只读。
录制保存一条入口到出口的完整固定路径，复用已有保护进路表、定义事务、编辑许可和世界 sidecar。
不修改 Core/Basic/ATO或公共服务，不新增资源申请或道岔切换。
本合同只描述录制；同一工具新增的删除交互见[Wand删除进路与主信号重绑](section-authoring-wands.md#wand删除进路与主信号重绑)，录制本身仍沿用本合同。
录制使用当前sidecar schema；默认进路已取消，不保留该配置或设置界面。

## 玩家如何完成一次录制

用 `/simplesignals wand route` 领取工具；左键入口，Shift + 左键出口，查看当前实际通路后右键确认。
保存只允许有 `simplesignals.admin` 权限的玩家，在原世界持有该工具、已有有效连通预览时使用。
删除原录制命令，不保留平行入口。潜行左键不取消选择，更换入口或退出工具沿用既有选择清理。
没有完整预览、结果已失效或通路没有到达所选出口时，明确拒绝保存。
工具选点与粒子操作仍在玩家所属线程；保存交给后台 worker。

后台检查所捕获预览仍对应当前区域与物理选择，随后冻结其中的有序 `ProtectionRouteTraversal`。
冻结前还确认它仍是原会话当前有效的 `visible()` 结果；事件已使预览待重算时不能录制旧画面对应的结果。
用同一片段列表构造固定进路，而不是再寻路或再次择路。开始录制后道岔切换不改写这份已捕获路径；
线路结构或定义并发变化仍由现有事务的候选校验、基线检查与编辑许可处理。
成功后回复区域、进路 ID；失败时显示已有事务诊断。取消只能阻止尚未提交的操作，不撤销已经提交的文件。

## 进路表如何保存或替换

现有模型每个保护区域最多一张固定进路表。
若尚无表，生成稳定 namespaced table/route ID，以区域当前 revision 创建只含这条进路的表。
若已有表且所选入口—出口组合只有一条进路，替换它的完整路径，保留进路 ID、表 ID、其他进路及已有设备引用。
若该组合尚无进路，则添加一条新进路；相同完整路径仍无变化，不写盘、不推进 revision。
手工 JSON 表允许同组合有多条进路，工具不能任意挑一条覆盖或删掉其他绑定；不同路径的替换须明确拒绝该歧义，保留旧表。
编辑候选的 `regionRevision` 绑定当前区域 revision，交给原 catalog 严格检查全部旧、新进路；
不能沿用过期绑定版本进入区域修复时的“只保留有效进路”编译分支，静默缩减正在编辑的表。
新进路 ID 由插件生成，不新增名称字段；所有位置仍为 canonical AB 米数及 AB/BA 方向。
比较同入口、同出口和完整有向片段列表；保存同一出入口的不同支路是替换，不作为相同路径无变化。
旧进路若不满足当前区域规则，不得为了录制成功而清空、删除或静默修复它们；候选校验失败保留整张旧表。需要清理失效项并补缺失组合时，使用[明确的区域修复](automatic-protection-routes.md#已有区域的进路修复)，不能把此操作藏在通路录制中。

新区域的进路表由[自动进路生成](automatic-protection-routes.md)建立；已有无表区域首次录制仍可建立表。
配置固定进路表后，该区域寻路只使用表内完整进路；没有表时的自由选路语义不再适用。
这复用现有 `ProtectionRouteTableCatalog` 的中立完整路径编译，不新增启用状态或另一套寻路限制。
录制不会创建列车资源授权。

## 接口与正常数据流

公开服务不变；用户入口是上述鼠标操作。保存适配属于 SimpleSignals 私有 authoring 代码，消费
`RoutePreviewSelection` 和 `RoutePreviewComputation.path`，仅把一次表 upsert 交给
`SimpleSignalsWorldRuntimeManager.applyDefinitionPatch`。
私有入口为 `CurrentRouteRecording.record(selection: RoutePreviewSelection, value: RoutePreviewComputation, active: () -> Boolean): String`。
返回值沿用原事务的管理员诊断或成功/重复记录消息，不增加新的请求/结果层。
预览工具构造时必须接入这一保存函数；不提供“未配置保存器”的可选产品模式来保留旧测试构造方式。

```text
玩家右键捕获当前选择、有效预览与现有会话身份
  -> worker 验证捕获值仍有效，冻结显示过的完整路径
  -> 查该区域已有表；相同完整路径直接返回已有 ID
  -> 构造路径替换、新组合添加或首张表的 upsert patch
  -> 现有定义事务编译、申请编辑许可、准备文件、原子提交
  -> 回玩家所属线程回复；旧会话不接收迟到结果
```

## 线程、关闭与并发

鼠标确认不在玩家线程做图遍历、JSON 或文件 I/O。保存适配不在物理回调执行。
复用已有玩家 Choice 的 busy/active 状态，避免同一选择重复并发提交；不新增周期 token、请求去重缓存或长期录制队列。
保存期间不阻塞预览订阅或列车物理。会话取消、换工具、退出、换世界、世界卸载及插件停用继续使用已有关闭路径。
传给定义事务的操作有效性判定只读原有会话原子状态，不在提交回调读取 Bukkit 玩家状态或重新采样曲线。
该判定不能重新比较信号/道岔观测或要求预览结果一直不变；物理选择后来切换不等于玩家取消已冻结的录制。
同 UUID 新世界 runtime 不能接收旧选择；并发定义编辑失败时不给旧 patch 自动重试或覆盖新内容。

## 拒绝条件与保留状态

不连通、等待观测、区域不可用、边界已变、选择已换或观测中的相关道岔已变：冻结路径之前拒绝，不写盘。
冻结后物理道岔选择改变：路径仍为录制时的固定值，不持有道岔资源来阻止切换。
候选非法、旧表不适用、编辑许可冲突、拓扑/定义基线改变、保存失败：沿用原有事务结果，磁盘、表和运行 source 保持原状态。
被已应用时刻表或列车占用保护的区域不能通过鼠标录制绕过编辑保护。
路径替换仍通过完整进路合法性和编辑保护校验，不改变Basic运行期冲突仲裁。

## 成本与限制

设录制路径有 P 个片段、表中已有路线片段总数为 T。创建路径值及完整路径比较约为 `O(P + T)`，
查找所属区域和表分别随世界定义中的区域、表数增长，入口/出口核对另随区域边界数增长；
复制旧表并保存替换仍随已有路线数量增长。检查相关道岔沿用预览实际查询集合，不扫描所有列车或信号。
定义候选编译、编辑影响和文件编码沿用现有事务成本，可能随世界定义规模增长，均在 worker；
不能把整次保存声称为仅 `O(P)`。没有新增 tick 工作、寻路、粒子采样或全世界资源扫描。

## 使用情形与必须验证

直向录制后改侧向：未保存时表不变；右键确认后同一出入口的路径被替换，进路 ID 及设备引用保留。

错误出口或尚在等待观测：预览仍能解释失败，但右键不能保存失败前缀。
受运营保护的咽喉：真实 Basic 编辑许可拒绝，不能仅测试脚本化的失败结果。

## 存档和后续事项

只填充已有 `routeTables` 字段，schema 保持1，没有新增旧格式兼容、文件或迁移。
进路删除与保护主信号重绑的当前状态归上述工具合同，不能与完整TextDisplay编辑显示、表示器映射作者界面的后续工作混称。默认进路配置已取消。
不得把预览成功当作授权，也不得保存时另找更短路径并让显示与记录内容不同。
