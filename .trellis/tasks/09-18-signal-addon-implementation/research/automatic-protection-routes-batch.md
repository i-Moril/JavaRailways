# 保护区域自动进路与鼠标替换批次

## 已批准的行为

新保护区域闭合时，为各有向入口—出口组合记录一条沿轨道距离最短的合法路径。
多条合法路径时仍可使用所选最短路，但相关入口、出口显示警告，不在内部道岔标记。
独立进路工具左键选择入口、Shift + 左键选择出口并预览，右键确认保存或替换。
保存当前道岔真实通路，不另寻最短路；替换保留已有进路身份与引用。

## 最小缺口和负责范围

- 新区域创建目前只提交边界。应在现有 worker 中构造区域与自动进路表的同一 patch。
- 当前录制使用命令且追加不同路径。改为鼠标确认及对应出入口路径替换，删除旧命令和潜行取消手势。
- 当前区域 Wand 没有多通路标记。增加相关出入口的临时、仅编辑玩家可见的警告，
  复用工具显示生命周期和预算，不新增通用业务注册表。
- 写共用视觉规范首版，不同时替换所有工具显示。

实现 agent 负责 SimpleSignals 生产代码与测试；main 负责规范、README、任务、提交与 journal。
不改 Core、Basic、SimpleATO 或宿主公共 API；不新增存档版本、旧格式兼容或自动资源申请。
修复区域保留原表，不覆盖玩家选择。时刻表与运行占用的防编辑规则继续成立。
新区域没有任何方向合法的入口—出口路径时，明确拒绝完成候选，原定义及待补全边界保持不变；
不能以没有进路表的宽松区域代替失败的自动建造，也不部分保存最后一次边界点击。

## 算法及验证关注点

限定于已识别区域内部，使用合法有向 continuation、边界切口和公共运营方向。
以轨道长度为权重、稳定顺序解等长候选。多通路检测无需枚举并保存全部路径；
环线必须终止，不能把多绕一圈的 walk 当作另一条简单进路，不能按无向邻接穿越道岔。
图搜索、几何、候选编译及文件工作在 worker；复杂度必须包含多通路检测和事务准备成本。

验证唯一/多通路、方向过滤、不可达、等长、环线、警告位置、原子失败及修复保留，
鼠标交互、迟到关闭、稳定 ID/default 引用、无变化保存、防编辑及重载后的实际寻路。
串行运行聚焦与完整 SimpleSignals 检查、Java API consumer 编译、JAR 隔离。
离线平台替身不能证明真实 Folia/客户端显示或规模延迟表现。
