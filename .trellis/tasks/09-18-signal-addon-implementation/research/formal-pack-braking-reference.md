# 正式四灯包的常用制动参考值

日期：2026-10-16。用户授权查询城市轨道交通常用减速度，并按调查结果直接选定本包参数。

## 来源与适用范围

交通运输部《城市轨道交通信号系统运营技术规范（试行）》（交办运〔2022〕1号附件）第5.2条，印刷第7页、PDF第7页，为ATO站台精确定点停车提供0.5–0.7m/s²的目标减速度范围。已读取官方PDF正文并核对对应页面，不使用搜索摘要中的车辆性能指标替代日常ATO目标。

来源：[交通运输部官方PDF，第5.2条](https://xxgk.mot.gov.cn/2020/jigou/ysfws/202201/P020220121613617393399.pdf)。

该条针对ATO站台停车，不是全部城市轨道交通车辆的统一实测减速度，也不是最大常用制动、紧急制动或所有速度/坡度条件的能力保证。这里引用2022年文件作为参数依据，不作2026年法规现行性或系统符合性声明。

## 本包取值

采用范围中值0.6m/s²，由正式信号包的logic YAML显式声明：

```yaml
reference-deceleration-metres-per-second-squared: 0.6
```

中值选择是本项目包作者的工程取值，不是来源规定必须使用0.6。继续按整个受控区间的最高有效轨道速度计算`D = v² / (2 × 0.6)`，由已有准备流程缓存；JS读取同一参考值，不硬编码另一份减速度。

通用loader仍要求每个逻辑显式选择固定距离或参考减速度，不增加全局0.6默认值，不修改ATO/Basic实际制动或逐车查询。其他作者的包可以配置不同的正有限减速度。

## 交付边界

本次仅固化已授权选择的包参数。仓库的JR四灯分发目录当前仍是模型/客户端资源示例，没有完整正式logic/signal包；不得单独添加缺配对JS的YAML，让真实loader读到一个残缺包，也不能改本地smoke输入声称正式交付。该参数须随下一笔完整JS信号包、直接消费交付文件的回归及规则说明一起落盘。
