## 优先级与修复批次

1. **资源安全**：CR-037 环线分次授权产生嵌套保留区间，换向释放索引可能提前释放仍被车体占用的资源；CR-038 暂停释放后仍接受普通授权扩展。先在现有 engine 测试中复现，再一起修复，不更换资源身份或正常释放算法。
2. **恢复边界**：CR-039 后续空白 WayPoint ID 导致部分写入；metadata UUID 大小写别名绕过重复检查并覆盖。统一在写入前解析、校验，不引入回滚框架或旧格式兼容，不升版本。
3. **几何正确性**：CR-040 五段/S 曲线坡道仍输出水平距离作为三维弧长；水平半径的分母使用三维弧长；偏移/竖曲线重建后复用中心线分段比例。三者应集中修复并补独立几何预期。安全曲率公式的物理模型需要单独说明，不能直接断言造成超速。
4. **配置 UI**：CR-041 隐藏子组未移除已展开条目，Bukkit renderer 又从原始子组补回隐藏字段并产生重复；快照实际为 live view。集中修复 producer/consumer，不为未经证实的并发使用增加全局锁。
5. **维护收尾**：已有 CR-002/005/020/032/033 继续承接文档、隐藏 API 类型、弱测试、空占位、旧保护字段和 fixture 清理。不要把全部 P3 清零作为正式游戏测试前提；也不能让 P1/P2 被零散清理挤到后面。

## 七维质量结论

### 1. 逻辑

模块分层总体成立：通用图算法、物理资源底线、claim/preparation/grant/车尾释放由 Basic 统一；信号制式和运营策略没有回流。观察值的复制、同 epoch/root 校验和区域占用连续性有明确不变量。

但资源释放、恢复原子性、几何距离尺度及嵌套 UI 存在已确认缺陷，不能称为“Basic 已通过”。当前测试遗漏了组合条件，尤其环线滚动授权再折返、坡度加曲率、子组隐藏加平台渲染。

### 2. 可维护性、可读性与文档

动力学计算复用同一纯引擎，准入拆为投影、资源编译、claim、准备及释放，职责优于再引入另一套 MA/信号资源系统。大文件并不自动等于面条代码，不建议仅按行数重构。

ConfigUIRegistry 同时承担注册、会话、视图构建，快照与线程安全的文档强于实现，需要有边界的语义修复。曲线的距离参数和分段元数据传递缺乏一致约束，是几何问题的共同来源。

Trellis 已说明多数非平凡算法，但仍有寻路复杂度漏项、部分历史模块表述、测试矩阵与实际覆盖不符。Dokka 的公共 `GradeAwareBrakingEnvelope.fromDynamics` 暴露被隐藏的 `TrainDynamics` profile 类型。网页架构仍把运营/时刻表放在 Basic；docs-site 已有用户脏状态，本轮不覆盖。Basic 及 persistence 代码地图的失效路径已在忽略的本地地图中修正，不宣称全仓地图已刷新。

### 3. 错误处理与过度兜底

保留 identity、拓扑/epoch、设备准备与卸载的拒绝检查：它们防御实际生命周期，不是“几乎不可能”的兜底。未发现需要为 JS 新增扫描数量、超时预算或通用 fallback 的依据。

真正的错误处理缺口在于预校验不完整和换向生命周期没有在 Basic 层统一拒绝。修复应落在状态所有者，而非依赖 SimpleATO 调用方已有 guard。任意 profile 的 NaN、并发配置注册等问题缺少实际生产触发证据，记录契约疑问，不添加每 tick 重复校验或锁框架。

### 4. 旧代码

空 `CurveEditor`、未使用的顶层超高过渡 enum、测试专用的旧 committed-suffix seam 可以评估清理。旧每端保护距离 payload 和未读取的默认配置字段仍被序列化/复制，不能当作纯死代码随手删。

`ManualController` 仍被开发命令与测试使用；不是正式手动驾驶控制器，也不是无人使用代码。其“紧急制动立即清零”注释不符实际，应修正文档或明确开发归属。公开扩展 API 不仅凭没有仓库内调用删除。

### 5. 规范一致性

Basic API 的 immutable value 与平台隔离基本统一，但 profile 类型泄露、配置快照定义和局部可变集合仍不一致。坡道曲线模板使用不同距离尺度属于实质不一致，优先于中英注释、装饰性分隔线等风格问题。

### 6. 测试

385 项测试不应按数量删除。队列顺序、物理资源准入、不可变快照、占用连续性、动力学独立数值及历史几何回归都有价值。

明确应改的是：零进度 helper 没执行 update 的空跑断言；曲线生成测试传错 tangent；非空 wrapper 重复断言；若干 world fixture 未关闭。必须补资源、恢复、坡道组合和嵌套 UI 的实际回归。安全监测现有三个算法测试不能证明真实 coordinator 的 epoch 集成；swept minimum、多车隔离、stale/future drain 等要求仍未覆盖。
