# 完整领域功能的隔离模拟与物理 epoch 事件

## 目标与价值

时刻表模拟应执行当前已安装铁路插件的完整领域功能，并拥有独立的运行状态，使验证结果反映真实运营、信号和碰撞规则，同时不改动实际世界、不长期阻塞实际运行。

## 已确认范围与基线

- 用户于2026-10-18明确：全Feature不包括Bukkit实体、玩家交互、方块和实际显示；领域算法、运营、信号、碰撞及影响运营结果的车厢行为逻辑在范围内。
- 当前模拟是静态设施快照加时刻表合成列车的验证运行；本任务保持这个初始条件，不变成复制在线列车/预约/Dispatcher状态的checkpoint分叉。
- 统一接口携带当前World实例；World携带运行模式。不引入独立environment层，不在每次事件发布时重复验证对象归属，不给每个事件复制多种环境ID。
- Pre/Post按每个真实物理epoch发布，不依赖WorldManager宿主tick。事件仍有所属World来源；正常唤醒、fallback和模拟都覆盖。失败epoch有Pre而无Post，成功发布完整结果后才有Post；用户已确认。
- 用户已要求先整合坐标统一与UI改进：当前基线为`dev/signal-system@a76b076c`，其双亲为`401f239c`与`12589555`，坐标实现`6548a850`已包含；合并验证为108项前端测试及生产构建通过。这不代表本任务运行时验证已执行。
- 当前工作区仍有其他会话的未提交改动，包括Core协调器/日志、信号编辑与规则、模型和docs-site。实现必须保留这些内容，基线清单见`research/current-state.md`。

## 需求

- **R1 完整领域功能**：实际与模拟复用同一物理、动力学、安全、ATO、时刻表、选路、资源claim/准备/释放和运营规则。已启用的固定闭塞、保护区域、进路选择、inspection、信号JS与限制投影必须在模拟中运行；不允许以空贡献集合、略过规则或简化算法充作完整支持。
- **R2 运行隔离**：每个World有独立可变运行状态、正常逻辑执行归属和生命周期；模拟不复用实际世界的列车、预约、provider运行实例、脚本状态、逻辑时钟或可变任务。实际World与模拟、两个模拟可独立推进；必要的跨世界管理事务仍正确协调。
- **R3 统一事件来源**：8个现有铁路运行事件通过同一接口取得World，监听器可据其运行模式区分来源。列车事件复用`train.world`；碰撞不再只提供字符串世界标识。保持原有业务决策和成功通知语义，不新增事件发布校验框架。
- **R4 逐物理epoch通知**：每个实际开始执行的epoch恰有一次Pre；成功完整发布后恰有一次Post，含匹配的World/epoch。失败、未启动、合并到已有ticket的唤醒不产生伪成功或重复通知。通知是物理阶段事件，不宣称平台效果完成；沿用普通listener异常隔离行为。
- **R5 删除模拟功能旁路**：删除模拟关闭碰撞事件的特判；保留相同碰撞决策及结果应用路径。车门/模型操作执行真实逐车行为和完成规则，模拟仅替换平台效果及时间推进出口，不能继续只估算配置时长。运营扩展必须使用属于模拟World的实现和状态。
- **R6 范围与实现风格**：复用现有World、协调器、事件总线、资源仲裁和信号编译器；只增加实际需要的模块接线。缺少当前运行所需的领域Feature时，模拟在准备边界明确失败，不能静默省略后报告通过。不得借本任务添加任意旧开发数据兼容、无依据schema升版、重复业务实现或通用沙箱框架。

## 验收标准

- [x] **AC1 / R2,R3**：不同World实例及LIVE/SIMULATION来源可直接从事件取得；换向、脱轨、过信号、碰撞、联结/解编的决策及成功事件全部覆盖，同名列车不会使监听器状态串用。
- [x] **AC2 / R4**：真实协调器回归覆盖普通/fallback/模拟、空世界、合并唤醒、处理失败、关闭/取消和listener异常；Pre在本轮计算前，Post只在完整frame发布后，epoch与frame一致。
- [x] **AC3 / R1,R5**：同一碰撞fixture在实际模式与模拟模式触发相同决策和联结/脱轨结果；无`publishCollisionEvents=false`或等价模拟专属旁路。
- [ ] **AC4 / R2**：用barrier证明World A或模拟A被暂停时，独立World B能推进；同一World操作仍串行且与物理帧间合同一致。重载/注册/卸载不会在检查后又出现未协调的新活动状态；关闭只释放所属运行资源。
- [ ] **AC5 / R1,R2,R6**：使用正式信号JS、真实区间/保护进路/inspection及资源贡献链，验证占用停车、释放放行、进路准备、折返和不可用规则；固定输入下的实际模式fixture与模拟结果对照，不以手写空source代替SimpleSignals接线。
- [ ] **AC6 / R1,R2,R5**：逐车脚本状态、方向、拒绝、延迟效果、取消及完成时机在两模式符合相同业务规则；模拟没有Bukkit效果，实际运行状态与资源不被误用，诊断正确标识所属模拟World而非实际World故障。缺失必需Feature的请求明确失败。
- [ ] **AC7 / R1-R6**：完成受影响模块回归、API消费/构建边界检查及最终并发集成验证；保持已合入UI/坐标行为、无关WIP及现有持久化格式。分别记录源码、自动测试和未执行的现场验证。

## 非目标

不模拟Bukkit平台本身、不安装或迁移开发服、不推送、不重做UI、不改变信号制式/碰撞规则、不新增跨世界铁路业务、不承诺同JVM内CPU/GC/崩溃的进程级隔离。本任务不顺带完成全部SimpleSignalsBukkit模块拆分或所有模型/authoring平台解耦。
