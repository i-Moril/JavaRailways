# 复用车厢行为逻辑并验证完整模拟隔离

## 目标

模拟运行真实逐车脚本和运营扩展，以独立逻辑调度/效果出口保持业务决定和完成时机。

## 需求与来源

本任务实现父任务的R1、R2、R5、R6的行为/扩展部分；父任务AC6及AC7相关部分。
完整用户决定与非目标以[父PRD](../10-18-isolated-simulation-runtime/prd.md)为唯一来源，不另行放宽。状态保持planning，尚未批准实现。

## 验收标准

- [ ] 同一真实脚本在两模式的独立车厢状态、门侧/换向、动作选择及拒绝一致。
- [ ] 多个延迟效果、失败、取消及全部完成时机使用相同业务规则。
- [ ] 不触发实际显示/声音，诊断可区分所属World；两个同源模拟不共享脚本、ticket或定时状态。
- [ ] 运营扩展实例属于目标World；缺少必需领域能力明确失败。
- [ ] 与真实SimpleSignals、碰撞及时刻表联合场景运行，向父任务提供并发隔离fixture。

## 范围限制

不部署、不迁移、不推送，不修改无关WIP，不新增Environment、逐次发布归属校验或未要求的兼容路径。仅修改本子任务拥有的部件；全Feature结论由父任务联合验收。

## 依赖

依赖10-18-world-runtime-isolation；本子任务最终联合验证也依赖10-18-simulation-signal-features。
