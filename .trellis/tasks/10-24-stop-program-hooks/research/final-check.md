## Confirmed issues found and fixed during this final check

### P1: optional INLINE start tick rejected on server save

`DutyManagement` creates INLINE with no `tick`, and its optional control clears to undefined; `authoring.ts` intentionally generates untimed `.program` in that case. Java `EditorDocumentValidator` passed a required field set containing `tick`, so valid UI-created inline duties failed persistence with 400.

Fixed the Java boundary to add `tick` to the exact field set only when present; present ticks still undergo integral/nonnegative/safe-number validation. Added a regression to `SharedStationProgramValidatorTest` for missing tick, valid tick, negative tick and null. Root must run WebUI tests after this fix. No frontend semantics were changed by the reviewer.
