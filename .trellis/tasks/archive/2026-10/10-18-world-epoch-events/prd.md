# 统一 World 来源事件并接入物理 epoch 通知

## 目标

运行事件可直接识别所属World，所有执行模式都按真实物理epoch通知，并完整执行碰撞事件。

## 需求与来源

本任务实现父任务的R3、R4，以及R5的碰撞事件旁路；父任务AC1-AC3对应部分。
完整用户决定与非目标以[父PRD](../../../10-18-isolated-simulation-runtime/prd.md)为唯一来源，不另行放宽。用户于2026-10-18在最终方案摘要后回复“可以”，批准从本批开始实现。

## 验收标准

- [x] 8个事件来源、两种模式、同名列车与两个World实例。
- [x] 真实coordinator的普通/fallback/模拟、空World、合并唤醒、失败/关闭、listener异常。
- [x] Pre先于计算；Post读取本次完整已提交frame；callback不在提交锁内执行。
- [x] 相同碰撞fixture在两模式都可决定LINK或默认DERAIL，无模拟旁路。

2026-10-18实现与独立检查完成，证据见[本批验证记录](research/validation.md)。当前候选在独立工作区，用户于2026-10-19批准本地提交，本批已完成主分支整合；不代表全隔离、全Feature模拟已经完成。
