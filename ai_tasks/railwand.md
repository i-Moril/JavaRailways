# RailWand 纵断面平滑实施计划

## 已确认行为

### 默认创建模式

- 创建新曲线段时，允许联合重算创建方向后方至多一条相邻普通曲线段。
- 相邻段与新段通过删除旧轨道、创建替代轨道实现；全部变更属于一个原子事务和一次撤销。
- 水平轨道是硬约束，整段必须保持水平；标准道岔几何不参与重算。

### 默认连接模式

- 连接两个既有端点时，允许左右两侧各联合重算至多一条相邻普通曲线段。
- 最多联合求解“左邻段 + 新连接段 + 右邻段”。某侧为水平轨道或道岔边界时，该侧保持固定，另一侧仍可参与。
- 替换、新建、拓扑恢复和引用迁移必须全体成功或全体回滚，并作为一次撤销。

### 坡度平滑模式

- 新增独立 RailWand 坡度平滑模式，只选择既有锚点，不创建额外控制点。
- 选择单个普通锚点 A1 时，联合重算 A0-A1 与 A1-A2；A0/A2 是固定外边界。
- 选择连续锚点 A1..An 时，重算连接选中区间并向两侧各扩展一条相邻普通曲线段。
- 锚点位置、高程、yaw、roll 固定，重新求解 pitch 和段内纵断面。
- 明确的局部最高/最低锚点强制 pitch=0；水平轨道整段强制水平。
- 无需预览，整个操作一次撤销。

### 并行线路

- 不新增或依赖持久化锚点对应关系；每次操作根据锚点位置、无向切线、横断面和横向排序临时验证及配对。
- 并行创建时，每条线最多重算后方一段；并行连接时，每条线左右各最多重算一段。
- 坡度平滑选择按几何横断面解释，所有线路联合求解、全体成功或全体不变。
- 必须验证数量、横断面共线、切线平行、间距、左右顺序、无交叉及非分岔普通拓扑。

## 实施阶段

### Phase 1：纯纵断面求解器（TDD）

1. 在 Basic 增加与 Bukkit/CoreWorld 无关的纵断面平滑器。
2. 输入固定控制点里程/高程、外边界坡度、水平段和坡顶/坡底约束。
3. 以最小弯曲能量的分段三次 Hermite 联合求解自由锚点坡度；自由节点保持二阶连续，硬坡度节点保持一阶连续。
4. 将求解结果叠加到既有水平线形，重新构造 tangent/normal，并累计真实三维弧长。
5. 测试连续坡、对称/非对称拱桥、坡谷、单锚点两侧、水平硬段、反向曲线和无效输入。

### Phase 2：几何并行约束（TDD）

1. 增加无持久化关系的横断面验证与横向排序工具。
2. 验证 T/-T、间距容差、高程平面、数量、顺序和交叉风险。
3. 纵断面以临时中心参考求解并应用到全部线路；任何线路失败则整体失败。

### Phase 3：轨道替换事务与撤销（TDD）

1. 抽取可复用的轨道快照：curve、metadata、渲染模板、拓扑连接和轨道内运营对象映射。
2. 先离线生成全部替代曲线，再在主线程原子替换。
3. 失败恢复旧轨道、拓扑、渲染和引用。
4. 新增整体 ReplaceRails WandAction；Undo 恢复旧集合。现有 RailWand 创建/替换操作不提供 Redo，本任务不额外扩展 Redo 语义。

### Phase 4：默认创建/连接接入

1. 创建模式识别后方唯一普通相邻段并联合重算；水平/道岔边界不修改。
2. 连接模式分别识别左右唯一普通相邻段，最多联合重算三段。
3. 并行操作按几何横断面识别，禁止部分替换。
4. 保留现有异步曲线生成、主线程提交及 heavy-operation gate。

### Phase 5：坡度平滑模式

1. 新增 `GRADE_SMOOTH` 模式和交互处理器。
2. 左键按路径选择既有锚点；右键执行；空白左键清空。
3. 单锚点扩展两侧一段；连续选择向两侧各扩展一段。
4. 道岔负责确定/终止路径，标准道岔段不重建。
5. 操作后刷新端点锚点选择和显示。

### Phase 6：回归与文档

- 运行 Basic/BukkitPlugin 单测、静态编译和相关集成测试。
- 验证创建、连接、并行、水平轨道、坡顶/坡底、道岔边界、失败回滚、Undo/Redo。
- 更新 `.codeabs` 对受影响目录的导航摘要。

## 持久化边界

- 本功能不新增锚点并行对应关系，不改变轨道存档 schema。
- `GRADE_SMOOTH` 是稳定能力名称，不以 V1/V2 表示。
- Wand 玩家状态若持久化模式枚举，仅使用现有字符串字段的新枚举值；不增加运行时旧开发数据兼容分支。
- 轨道替换产生的新 ID 时，必须在事务中迁移当前模型引用；不得通过长期 legacy ID 兼容路径解决。
